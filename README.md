
# DIPLab Studio

A desktop application for Digital Image Processing and photo editing using Python, Tkinter, OpenCV, and NumPy.

## About the Project

DIPLab Studio is a Digital Image Processing lab project developed by students of the Department of Computer Science and Engineering at Hamdard University Bangladesh.

The main goal of this project is to create an easy-to-use desktop application where users can open an image, apply different image-processing operations, compare results, and save the edited image.

## Features

### Basic Image Processing
- Grayscale conversion
- Black and White conversion
- Negative image
- Contrast stretching
- RGB channel visualization

### Photo Editing
- Brightness adjustment
- Contrast adjustment
- Saturation adjustment
- Warmth adjustment
- Sharpness adjustment
- Image rotation and flipping
- Crop and resize
- Photo filters and effects

### Additional Features
- Original and edited image comparison
- Undo and Redo
- Image histogram
- Pixel intensity profile
- Save edited images
- Scrollable editing tools panel

## Technologies Used

- Python 3.12
- Tkinter — Desktop user interface
- OpenCV — Image processing
- NumPy — Numerical operations
- Pillow — Image editing and display
- Matplotlib — Histograms and image analysis

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/IFTE899/DIPLab-Studio.git
```

### 2. Open the project folder

```bash
cd DIPLab-Studio
```

### 3. Install required libraries

Make sure Python 3.12 is installed.

```bash
python -m pip install -r requirements.txt
```

### 4. Run the application

```bash
python main.py
```
